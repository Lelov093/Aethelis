# Mistgate Product Content v1

This directory is the first product-content package for Mistgate. It converts the immutable
research source under `seeds/mistgate_v01` through a pinned source hash; it does not replace
or rewrite that research evidence.

The package defines the P2 product-content contract: Simplified Chinese
localization, arrival/onboarding, public routes, initial player actions, safe presentation
metadata, save compatibility, and the approved art/AI-asset policy. P2 Work Block 2 added
and connected five location scenes plus the Mira and Rowan portraits; each approved slot
references its checked-in provenance record. Later-work-block asset slots remain planned.

P2 Work Block 3 published `mistgate_product_v1_7_0`. It includes the
governed pressure repair and commitment fulfillment/breach state, then adds lawful
calibration-key release, gate-lens validation, and the definitive regulator ending. Every
step is gated by persisted discovery, custody, knowledge, and target state; older timelines
remain pinned to their published package versions. After the ending, one governed wait action
allows Selka to initiate a persisted branch-specific city response: civic supply coordination
after fulfillment or support withdrawal after breach. This is bounded autonomous activity,
not a claim of continuous background simulation.

P2 Work Block C publishes the active immutable package as `mistgate_product_v1_8_0`. The
product snapshot now carries bounded world time and server-private character cognition from
the pinned Mistgate seed. Safe free conversation works without an authored topic; a player
claim can become a source-attributed, low-confidence listener belief and later propagate on a
governed world turn without becoming Canon. The player can also consult a visibility-limited
world-narrative surface or deliberately wait for one bounded independent/cooperative Agent
step. Older package rows remain compatible through narrow version-specific hashes.

The Work Block C dialogue-experience closure publishes `mistgate_product_v1_9_0`. Dialogue
turns may now carry a client-created interaction ID so several governed commands can be
projected as one mixed preset/free conversation and reconstructed after save, resume, or fork.
The identifier groups already committed turns only; it grants no knowledge, permission, effect,
or Canon authority. Existing v1.8 timelines remain pinned and playable, while the client gates
unsupported free-dialogue controls on older content versions instead of offering a guaranteed
rejection.

Work Block D publishes `mistgate_product_v1_10_0`. Its opportunity contract carries explicit
player-visible completion evidence, so the journal derives active, optional, and completed
threads from snapshot truth instead of displaying one permanent checklist. Market parts,
workshop key custody, and aqueduct lens validation can progress in different orders; blocked
repair and calibration attempts return content-authored recovery directions. The technical
ending still preserves the independently fulfilled or broken Selka commitment.
